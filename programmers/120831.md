## 문제와 풀이 의도

주어진 정수 `n`까지의 양의 짝수 합을 구하는 문제입니다. 공식 범위는 `1 ≤ n ≤ 1000`입니다.

`mid_n = n // 2`로 짝수의 개수를 구한 뒤, `i`를 1부터 그 개수까지 증가시키며 `2 * i`를 더합니다. 짝수만 한 번씩 방문하므로 불필요한 홀수 검사가 없습니다.

## 올바름과 검증

정적 검토: 만들어지는 값은 `2, 4, …, 2 * (n // 2)`이므로 `n` 이하의 모든 양의 짝수를 빠짐없이 한 번씩 더합니다. `n = 1`이면 반복 없이 초기값 0을 반환합니다.

실행 검증: 위 소스 커밋의 함수를 Python3로 실행하여 **1~1000의 모든 정수 입력 1,000개**를 비교했고 모두 일치했습니다. 독립 기준값은 1부터 n까지 각 정수가 짝수인지 검사해 합산하여 계산했습니다. 온라인 저지 제출 결과를 확인한 것은 아닙니다.

| 입력 | 실제 반환값 | 확인한 경우 |
| --- | --- | --- |
| 1 | 0 | 짝수가 없는 최소 입력 |
| 4 | 6 | 공식 예시 |
| 7 | 12 | 홀수 상한: 2 + 4 + 6 |
| 10 | 30 | 공식 예시 |
| 1000 | 250500 | 최대 입력 |

## 복잡도와 피드백

- 시간 **O(n)**: 정확히 `n // 2`회, 공식 범위에서 최대 500회 반복합니다.
- 추가 공간 **O(1)**: 입력 크기에 따라 커지는 별도 자료구조가 없습니다.
- 현재 풀이로 공식 범위의 요구를 충족합니다. 추가 함수화는 필요하지 않습니다.
- 선택 사항: `mid_n`을 `even_count`로 바꾸면 “짝수의 개수”라는 역할이 더 분명해집니다.
- 학습 확장: 짝수들의 합을 등차수열로 보면 반복 없이 계산할 수도 있습니다. 현재 풀이를 바꿀 필요는 없고, 왜 같은 합이 되는지 생각해 보세요.
