# 120854 · 배열 원소의 길이

[문제 원문](https://school.programmers.co.kr/learn/courses/30/lessons/120854) · [검토 코드](https://github.com/JamtolSin/CodingTestPrepare/blob/0c63c78d881340cd667a4acce51c8a7a5b13087c/programmers/120854.py)

문자열 배열의 각 원소 길이를 원래 순서대로 반환하는 문제입니다. 원소별 문자열 길이는 1~100이며, 공식 원문에는 배열 원소 개수의 상한이 명시되어 있지 않습니다.

## 풀이와 피드백

문자열을 차례로 방문해 `len(str)`를 결과 배열에 추가합니다. 각 원소를 한 번씩 처리하고 순서를 유지하므로 요구한 결과를 만듭니다.

- 문자열 개수를 n이라고 하면 시간 **O(n)**입니다. Python 문자열의 `len`은 저장된 길이를 읽는 **O(1)** 연산이며, `append`는 분할상환 O(1)입니다.
- 반환 배열은 **O(n)** 공간을 사용합니다. 출력 배열을 제외한 보조 공간은 **O(1)**입니다.
- `str`는 Python 내장형 이름을 가립니다. 현재 코드에서는 오답 원인이 아니며, 다음 풀이에서는 `word` 같은 이름을 선택하면 의미가 더 분명합니다. 원본 변수명과 풀이는 그대로 보존했습니다.
- 추가 함수화는 필요하지 않습니다. 선택적으로 같은 순회를 리스트 컴프리헨션으로 표현하는 방법을 익혀볼 수 있습니다.

## 검증

온라인 제출 통과는 **사용자 보고**입니다. 별도로 Python3에서 아래 **304개 로컬 테스트를 실행했고 모두 통과**했습니다.

| 범위 | 결과 |
| --- | --- |
| 공식 예제 2개 | 각각 `[2, 3, 3, 6]`, `[1, 4, 12]`와 일치 |
| 길이 1·100 문자열을 하나씩 담은 경계 2개 | 각각 `[1]`, `[100]`과 일치 |
| 문자열 길이 1~100을 각각 확인한 100개 | 모두 일치 |
| 고정 시드 120854로 만든 무작위 배열 200개 | 모두 일치 |

추가 302개 테스트의 독립 기준은 문자열의 문자를 하나씩 세어 계산했고 입력 배열이 변경되지 않는 것도 확인했습니다. 무작위 테스트는 대·소문자와 특수문자, 문자열 길이 1~100, 배열 원소 수 1~200으로 구성했습니다. 배열 원소 수 범위는 테스트용 선택이며 공식 최대 제한이 아닙니다. 모든 가능한 입력을 전수 검사한 것은 아닙니다.
