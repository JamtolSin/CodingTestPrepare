# CodingTestPrepare

Python3로 코딩 테스트 문제를 풀고 기록하는 저장소입니다.

## 파일 경로

| 사이트 | 경로 |
| --- | --- |
| 프로그래머스 | `programmers/<문제ID>.py` |
| 백준 | `baekjoon/<문제ID>.py` |
| LeetCode | `leetcode/<문제ID>.py` |

## 사용법

Notion에 적힌 경로에 `.py` 파일 하나를 작성하고, 예제를 확인한 뒤 `main`에서 commit → push합니다.

```powershell
git add -- programmers/120831.py
git commit -m "solve: programmers 120831"
git push
```

다른 문제를 풀 때는 경로와 문제 ID만 바꾸면 됩니다.
